# Matcha-Flavored
Clone of [this Minecraft datapack](https://modrinth.com/datapack/matcha-flavoured), with slight tweaks to run the data-pack as a full mod, and make slight game-play changes
**README is a big WIP. It looks cryptic for now**

# Villages
Change the villages so that the villages spawned are not beta-villages. They spawn real villages with villagers you can properly trade with on the mod
- Village-beta was implemented by the dev as a JSON file.

# Smithing Templates
Smithing templates are what add the enchantment to the ingredients. THE ITEMS THEMSELVES DO NOT HAVE THESE ENCHANTMENTS
We can, as a result, modify the buffs of the item by looking into these ingredients.

# Smoking and Smelting
- Mud kiln was replacing the smoker
- Oven replaces the furnace

Of course, **EVERY DAMN ITEM HAS ITS OWN TIMER!**

`Smelting-Recipe`: Shows recipies and times for the campfire
`Smoking`: Is for the mud-kiln
`minecraft:smelting`: Is anything that refers to the oven
`Blasting`: Is for the blast furnace
